# Never Forget Claude - Backend API

Cross-platform todo list synchronization API built with FastAPI and PostgreSQL.

## Features

- ✅ RESTful API with automatic OpenAPI documentation
- ✅ UUID-based device authentication (no user accounts)
- ✅ Last-write-wins conflict resolution
- ✅ Batch synchronization endpoint
- ✅ Async PostgreSQL with connection pooling
- ✅ CORS support for cross-platform clients

## Tech Stack

- **Python**: 3.11+
- **Framework**: FastAPI 0.104+
- **Database**: PostgreSQL 15+
- **ORM**: SQLAlchemy 2.0 (async)
- **Server**: Uvicorn

## Prerequisites

- Python 3.11 or higher
- PostgreSQL 15 or higher
- pip (Python package manager)

## Quick Start

### 1. Install Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 2. Configure Environment

Copy the example environment file and update with your settings:

```bash
cp .env.example .env
```

Edit `.env`:
```bash
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/neverforget
CORS_ORIGINS=http://localhost:3000,app://android
PORT=8000
```

### 3. Initialize Database

Run the migration script:

```bash
psql -U your_user -d neverforget -f migrations/001_initial.sql
```

Or let SQLAlchemy auto-create tables on first startup (development only).

### 4. Run the Server

```bash
cd backend
uvicorn src.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at:
- **API**: http://localhost:8000
- **Docs**: http://localhost:8000/docs (Swagger UI)
- **ReDoc**: http://localhost:8000/redoc

## Docker Deployment

### Build Image

```bash
cd backend
docker build -t never-forget-api .
```

### Run Container

```bash
docker run -d \
  -p 8000:8000 \
  -e DATABASE_URL=postgresql+asyncpg://user:pass@host/db \
  -e CORS_ORIGINS=http://localhost:3000 \
  --name never-forget-api \
  never-forget-api
```

## API Endpoints

### Health Check
- `GET /health` - API health status (no auth required)

### Tasks
- `GET /tasks` - List all tasks (with optional `?limit=15` and `?since=timestamp`)
- `POST /tasks` - Create a new task
- `GET /tasks/{id}` - Get a specific task
- `PUT /tasks/{id}` - Update a task
- `DELETE /tasks/{id}` - Delete a task

### Sync
- `POST /tasks/sync` - Batch synchronization with conflict resolution

## Authentication

All endpoints (except `/health`) require a device token in the Authorization header:

```bash
Authorization: Bearer <uuid-v4-device-token>
```

Device tokens are randomly generated by clients on first launch.

## Development

### Code Style

- Follow PEP 8 guidelines
- Use type hints for function signatures
- Document all public APIs with docstrings
- Keep functions under 50 lines per constitution

### Adding New Endpoints

1. Create route in `src/api/`
2. Register router in `src/main.py`
3. Add tests if required
4. Update OpenAPI docs (auto-generated)

## Configuration

Environment variables:

| Variable | Description | Default |
|----------|-------------|---------|
| `DATABASE_URL` | PostgreSQL connection string | `postgresql+asyncpg://...` |
| `CORS_ORIGINS` | Comma-separated allowed origins | `http://localhost:3000` |
| `PORT` | Server port | `8000` |
| `HOST` | Server host | `0.0.0.0` |
| `DEBUG` | Enable debug mode | `False` |

## Troubleshooting

### Database Connection Errors

1. Verify PostgreSQL is running
2. Check DATABASE_URL format: `postgresql+asyncpg://user:pass@host:port/dbname`
3. Ensure database exists: `createdb neverforget`

### CORS Issues

Add your client's origin to CORS_ORIGINS in `.env`:
```bash
CORS_ORIGINS=http://localhost:3000,app://android,http://localhost:5173
```

### Port Already in Use

Change the PORT in `.env` or use a different port:
```bash
uvicorn src.main:app --port 8001
```
